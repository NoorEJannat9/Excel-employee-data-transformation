# Employee Sales Analysis Project

This project focuses on cleaning and analyzing a large-scale employee dataset to extract performance insights.

## Project Tasks
1. **Name Cleaning:** Standardized the "Name" column for consistency.
2. **Layout Optimization:** Adjusted column widths for better data visibility.
3. **Sales Calculation:** Created formulas to calculate individual sales amounts for every employee.
4. **Total Metrics:** Aggregated data to show the total sales across the organization.
5. **Performance Rating:** Calculated the average employee rating.

## Files
- `Class 4- Assessment Dataset.xlsx`: The original raw data.
- `Class 4- Assessment Noor E Jannat.xlsx`: The final cleaned and analyzed project.
